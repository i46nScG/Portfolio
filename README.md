# Tokioshy — Portfolio

My personal portfolio website for whatever it was... Looks cool, and I have `is-a.dev` subdomain, so why not.
Built with **Tailwind CSS** and plain HTML/JavaScript (no framework).

## Features

- Dark and light mode (follows the system setting on first visit, remembered afterwards)
- Responsive layout for mobile, tablet and desktop
- Full-screen desktop sections with slower smooth transitions and free scrolling on mobile
- GitHub profile avatar that follows the current profile image
- Interactive slash-command console in the hero (`/about`, `/projects`, `/stack`, `/contact`, `/theme`, `/clear`)
- Typing animation, scroll progress bar, scroll reveal, cursor glow and 3D tilt on project cards
- Project filter (All / Discord bots / Web apps)
- Respects `prefers-reduced-motion`

## Project structure

```
.
├── public/
│   ├── index.html        # Page content and layout
│   ├── favicon.svg
│   └── assets/
│       ├── index.js      # Minified build output from src/index.js
│       └── style.css     # Generated by Tailwind (do not edit by hand)
├── src/
│   ├── index.js          # Projects list, stack list, interactions
│   └── style.css         # Tailwind entry file, theme colors, custom animations
├── scripts/build.js     # Minifies src/index.js for public/assets/index.js
├── tailwind.config.js
├── vercel.json           # Build settings for Vercel
└── package.json
```

## Customizing

| What                                | Where                                                                                 |
| ----------------------------------- | ------------------------------------------------------------------------------------- |
| Name, bio, contact text             | `public/index.html`                                                                   |
| Projects, stack, typed roles, email | top of `src/index.js`                                                                 |
| Colors (light and dark)             | CSS variables in `src/style.css` (`:root` and `.dark`)                                |
| Fonts                               | Google Fonts `<link>` in `public/index.html` and `fontFamily` in `tailwind.config.js` |

To add a project, add an object to the `projects` array in `src/index.js`:

```js
{ name: 'My Project', lang: 'JavaScript', type: 'bots', // 'bots' or 'web'
  url: 'https://github.com/i46nScG/My-Project', desc: 'Short description.' }
```

If you use a new language, add its color to `langColor` in the same file.

## Run locally

Requires [Node.js](https://nodejs.org) 18 or newer.

```bash
npm install
npm run dev
```

Open <http://localhost:3000>. `npm run dev` rebuilds the CSS and minified JavaScript automatically when their source files change.

Other commands:

- `npm run build` — generate minified `public/assets/style.css` and `public/assets/index.js`
- `npm run serve` — serve the `public` folder without watching CSS changes

## Deploy

`vercel.json` already sets the build command (`npm run build`) and the output directory (`public`).
